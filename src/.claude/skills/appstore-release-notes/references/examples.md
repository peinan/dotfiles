# リリースノート実例集

App Store リリースノートの良い例を収録。生成時の参考にする。

## パターン 1: バグ修正のみ

**日本語**

```
• スプラッシュ画面で古いアイコンが一瞬表示される問題を修正
• 一部の設定が正しく保存されない問題を修正
```

**English**

```
• Fixed an issue where the old icon briefly appeared on the splash screen
• Fixed an issue where some settings were not saved correctly
```

## パターン 2: 新機能 + バグ修正

**日本語**

```
ダークモードに対応しました。

• ダークモード対応（設定画面から切り替え可能）
• 録音中にバックグラウンドへ移行しても録音が継続するように改善
• 一部端末で音声認識が途中で止まる問題を修正
```

**English**

```
Dark mode is here.

• Added dark mode support (toggle in Settings)
• Improved recording to continue when the app moves to the background
• Fixed an issue where speech recognition stopped unexpectedly on some devices
```

## パターン 3: 初回リリース / 大型アップデート

**日本語**

```
声にっきへようこそ！声で日記を書くアプリです。

• 音声録音とリアルタイム書き起こし
• AI によるタイトル自動生成
• 日記の一覧表示・編集・削除
• 完全ローカル動作（アカウント登録不要）
```

**English**

```
Welcome to Koe Nikki! A voice-first diary app.

• Voice recording with real-time transcription
• AI-powered automatic title generation
• Browse, edit, and delete diary entries
• Fully local — no account required
```
